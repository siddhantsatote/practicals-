# DSCH 3.5 Schematic Files for ASIC Flow & Digital CMOS Lab

All schematic files in this directory use standard DSCH 3.5 syntax (`v3.5`) and can be opened directly from DSCH 3.5 via:
**File -> Open -> Select .sch**

### File Directory:
- `Exp01_4bit_ripple_carry_adder.sch` : 4-bit Ripple Carry Adder schematic
- `Exp01_full_adder.sch`              : 1-bit Full Adder transistor schematic
- `Exp02_sram_6t_cell.sch`            : 6T Static RAM memory cell schematic
- `Exp02_ram_8x8.sch`                 : 8x8 Synchronous RAM array block
- `Exp02_rom_cell.sch`                : ROM transistor storage cell
- `Exp03_4bit_parallel_adder.sch`     : 4-bit Parallel Adder block schematic
- `Exp04_4bit_async_up_down_counter.sch`: 4-bit Asynchronous Ripple Up/Down Counter
- `Exp05_cmos_inverter.sch`           : CMOS Inverter schematic
- `Exp05_nand2.sch`                   : 2-input CMOS NAND gate schematic
- `Exp05_nor2.sch`                    : 2-input CMOS NOR gate schematic
- `Exp06_half_adder.sch`              : CMOS Half Adder schematic
- `Exp06_full_adder.sch`              : CMOS Full Adder schematic
- `Exp07_transmission_gate.sch`       : CMOS Transmission Gate schematic
- `Exp07_mux2to1.sch`                 : 2:1 Multiplexer using transmission gates
- `Exp08_xor2_cmos.sch`               : 2-input CMOS XOR gate schematic
