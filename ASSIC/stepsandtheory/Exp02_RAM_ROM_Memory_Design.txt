================================================================================
EXPERIMENT 2: Design, Synthesis and Simulation of RAM/ROM using Verilog (Behavioral)
================================================================================

AIM:
To design, simulate and synthesize RAM and ROM memory modules using Verilog/VHDL 
behavioral modeling and analyze hardware parameters such as LUT utilization, power, 
critical timing and delay estimation.

APPARATUS / TOOLS REQUIRED:
- Xilinx Vivado / ModelSim / Cadence Genus / Synopsys Design Compiler
- DSCH 3.5 & Microwind 3.5 (6T SRAM Cell and Memory Array Layout)

THEORY:
Memory plays a crucial role in computing devices, ensuring smooth data storage.
Two fundamental volatile RAM categories:
1. Static RAM (SRAM):
   - Uses cross-coupled CMOS inverters (6T cell: 2 PMOS load, 2 NMOS driver, 2 NMOS access).
   - Retains data continuously as long as VDD power is applied without refresh cycles.
   - High speed, low access latency (cache memory L1/L2/L3).
2. Dynamic RAM (DRAM):
   - 1T-1C cell (1 transistor + 1 storage capacitor).
   - High density, requires periodic refresh cycles.
3. Read-Only Memory (ROM):
   - Non-volatile storage matrix with hardwired values.

BEHAVIORAL MODELING OF RAM:
- 8 locations x 8-bit memory array: `reg [7:0] mem [0:7];`
- Synchronous write on positive clock edge: `if (we) mem[addr] <= din;`
- Synchronous or asynchronous read: `else dout <= mem[addr];`

SIMULATION PROCEDURE:
1. Open simulator, add ram_8x8.v and tb_ram_8x8.v.
2. Initialize clock (period = 10ns), write enable, address, and data.
3. Write test patterns (8'hAA, 8'hBB, 8'hCC, 8'hDD) to addresses 0, 1, 2, 3.
4. De-assert write enable (we = 0) and sequentially read addresses 0 to 3.
5. Verify that dout matches written data with zero corruption.
