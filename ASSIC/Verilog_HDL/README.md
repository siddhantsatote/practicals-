# Verilog HDL RTL Modules and Testbenches for ASIC Flow

This directory contains the complete synthesizable Verilog source code and automated self-checking testbenches for all ASIC experiments.

### Directory Contents:
- `Exp01_ripple_carry_adder_4bit.v` & `tb_rca.v`: 4-bit RCA design and testbench
- `Exp02_ram_8x8.v` & `tb_ram_8x8.v`: Synchronous 8x8 RAM and testbench (AA, BB, CC, DD write/read)
- `Exp03_parallel_adder_4bit.v` & `tb_parallel_adder_4bit.v`: 4-bit parallel adder
- `Exp04_up_down_counter.v` & `tb_up_down_counter.v`: 4-bit asynchronous up/down counter
- `Exp05_cmos_gates.v`: Inverter, NAND2, NOR2 behavioral models
- `Exp06_adders.v`: Half Adder and Full Adder modules
- `Exp07_mux_tg.v`: 2:1 Multiplexer and Transmission Gate models
- `Exp08_xor2.v`: 2-input XOR model
