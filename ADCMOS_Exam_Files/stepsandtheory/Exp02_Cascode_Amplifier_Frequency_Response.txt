==============================================================
EXPERIMENT 2 : FREQUENCY RESPONSE OF CASCODE AMPLIFIER
Complete start-to-finish guide  (tool: LTspice)
==============================================================

WHY LTSPICE AND NOT MICROWIND
Your journal shows this experiment in LTspice (AP9465GEM transistors,
.ac analysis, two overlaid gain curves). Microwind cannot do AC
sweeps with vendor transistor models, so LTspice is used.

AIM
To build a common source amplifier and a cascode amplifier on the
same sheet, run one AC analysis, and compare gain and bandwidth.

FINAL CIRCUITS (what you will have at the end)
 LEFT  (common source)            RIGHT (cascode)
  VDD1 = 12 V                      VDD2 = 15 V
  RD1  = 100 ohm                   RD   = 100 ohm
  CS1  = AP9465GEM                 CS (lower) and CG (upper)
  VB3  = 1.8 V + Vin1 (AC 1)         both AP9465GEM
  output Vo_cs                     VB1 = 1.8 V + Vin (AC 1) on CS gate
                                   VB2 = 1.8 V on CG gate
                                   output Vo_cascode
  One directive:  .ac dec 100 1 100meg


--------------------------------------------------------------
PART 1 : GET THE SOFTWARE AND THE TRANSISTOR MODEL
--------------------------------------------------------------
1. LTspice (free): browser > analog.com > search "LTspice" >
   Download for Windows > run installer > defaults > finish.
   (Lab PC already has it.)
2. AP9465GEM model: search the web for "AP9465GEM SPICE model" (maker
   APEC, a-poweric.com) or ask your lab teacher for the lab's file.
   Make folders  C:\ADCMOS\Exp2  and save the file there as
   AP9465GEM.lib.
3. Open AP9465GEM.lib in Notepad. Find the first line starting with
   .MODEL or .SUBCKT. Write down the name after it and whether it says
   NMOS or PMOS. Use the symbol that matches (nmos or pmos).
   No model file? Use the built-in transistor: add the line
     .model NMOD NMOS(Kp=0.2 Vto=1.5 Lambda=0.02 Cgdo=1n Cgso=1n)
   and set every transistor Value to NMOD (numbers will differ from
   the journal but all steps are the same).


--------------------------------------------------------------
PART 2 : NEW SCHEMATIC
--------------------------------------------------------------
4. Open LTspice. File > New Schematic.
5. File > Save As > C:\ADCMOS\Exp2\cascode.asc  > Save.

Toolbar keys: F2 component, F3 wire, F4 net label, G ground,
S spice directive, Ctrl+R rotate, Ctrl+E mirror, F5 delete,
F6 copy, F7 move, Esc / right-click to stop a tool.


--------------------------------------------------------------
PART 3 : DRAW THE LEFT CIRCUIT (COMMON SOURCE)
--------------------------------------------------------------
6. Transistor CS1
   F2, type nmos (or pmos per the model), OK, click in the grid to
   drop it, Esc. Right-click it; if your model is in the "Pick New
   MOSFET" list select it, otherwise Cancel and Ctrl+right-click the
   transistor to open the attribute editor and type the model name
   in the Value box. Right-click the name text and rename to CS1.
7. Resistor RD1: F2, type res, OK, drop it above CS1 (Ctrl+R to make
   it vertical). Right-click > Resistance = 100 > OK.
8. Voltage sources: F2, type voltage, OK. Drop three:
   - VDD1: right-click > DC value 12 > OK.
   - VB3 : right-click > DC value 1.8 > OK.
   - Vin1: right-click > DC value 0 > click Advanced > "AC
           Amplitude" = 1 > OK > OK.
9. Grounds: press G, click below CS1 source, below Vin1, below VDD1.
10. Wires (F3):
    VDD1(+) to top of RD1; VDD1(-) to ground;
    bottom of RD1 to CS1 drain; CS1 source to ground;
    CS1 gate to VB3(+); VB3(-) to Vin1(+); Vin1(-) to ground.
11. Labels (F4): type Vo_cs, click on the RD1/drain junction wire.
    F4 again: Vin_cs, click on the gate wire.


--------------------------------------------------------------
PART 4 : DRAW THE RIGHT CIRCUIT (CASCODE)
--------------------------------------------------------------
12. Place two transistors to the right, one above the other:
    lower = CS, upper = CG. (F2, nmos/pmos, set Value to the same
    model name, rename the texts to CS and CG.)
13. Resistor RD: F2 res, drop above CG, 100 ohm.
14. Voltage sources (F2 voltage):
    - VDD2: DC value 15
    - VB2 : DC value 1.8   (feeds the CG gate)
    - VB1 : DC value 1.8   (feeds the CS gate, in series with Vin)
    - Vin : DC 0, Advanced > AC Amplitude 1
15. Grounds: G, click below CS source, below Vin(-), below VB2(-),
    below VDD2(-).
16. Wires (F3):
    VDD2(+) to top of RD; bottom of RD to CG DRAIN;
    CG SOURCE to CS DRAIN (the two transistors stack);
    CS SOURCE to ground;
    CG gate to VB2(+); VB2(-) to ground;
    CS gate to VB1(+); VB1(-) to Vin(+); Vin(-) to ground.
17. Labels (F4): Vo_cascode on the wire between RD and CG drain;
    Vin_cascode on the CS gate wire.


--------------------------------------------------------------
PART 5 : MODEL LINE AND ANALYSIS COMMAND
--------------------------------------------------------------
18. Press S, type   .lib AP9465GEM.lib   , OK, click empty space.
    (If you used the built-in model, type the .model line instead.)
19. Simulate > Edit Simulation Cmd > tab "AC Analysis":
      Type of sweep: Decade
      Points per decade: 100
      Start Frequency: 1
      Stop Frequency: 100meg
    OK, click empty space. Reads:  .ac dec 100 1 100meg

20. Quick DC check (optional but recommended): replace the .ac line
    with  .op  , Run, look at the drain voltages of both circuits.
    They should be between about 1 V and 14 V and not stuck at the
    supply rail. Then restore the .ac line.


--------------------------------------------------------------
PART 6 : RUN AND READ BOTH CURVES
--------------------------------------------------------------
21. Click Run (running-man icon).
22. Click the Vo_cs net on the schematic (pointer becomes a red
    probe). Then click the Vo_cascode net. The plot now has two
    gain curves (solid) and two phase curves (dashed).
23. READ THE GAIN OF EACH
    a. Left-click the trace name V(vo_cs) at the top of the plot.
       A Cursor box shows Freq, Mag (dB), Phase.
    b. Drag the cursor to a low frequency (say 100 Hz). Write down
       Mag.
    c. Left-click V(vo_cascode) at the top for a second cursor and
       do the same.
    Your journal plot has one flat trace near 39 dB and one near
    27 dB.
24. FIND -3 dB FREQUENCY OF EACH
    For each trace: drag its cursor to the right until Mag is 3 dB
    below that trace's own mid-band value. Write down the Freq.
25. READ PHASE at 1 MHz for both traces.
26. SCREENSHOT: Windows key + Shift + S, drag over the plot, paste
    into Word/Paint. Do it for the schematic too.

--------------------------------------------------------------
IF SOMETHING GOES WRONG
--------------------------------------------------------------
Only one curve appears: click the second net as well, or use Plot
   Settings > Add Traces and pick V(vo_cascode).
Curve flat at 0 dB or empty: Vin / Vin1 AC Amplitude not set to 1.
Two circuits behave as if connected: you have a stray wire joining
   them. Delete (F5) any wire that crosses between the left and
   right circuits.
"Could not open library file": the .lib file is not in the same
   folder as cascode.asc.
