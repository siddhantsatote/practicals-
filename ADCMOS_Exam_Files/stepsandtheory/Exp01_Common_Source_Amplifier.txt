==============================================================
EXPERIMENT 1 : COMMON SOURCE AMPLIFIER
Complete start-to-finish guide  (tool: LTspice)
==============================================================

WHY LTSPICE AND NOT MICROWIND
Your journal shows this experiment drawn in LTspice (AP9465GEM
transistor, .ac directive, dB and phase plots). Microwind cannot run
AC sweeps or vendor transistor models, so this guide uses LTspice.

AIM
To build a common source amplifier, run an AC analysis, and find
its voltage gain, phase, and upper cutoff frequency.

FINAL CIRCUIT (what you will have at the end)
  VDD = 12 V DC
  RD  = 100 ohm (from VDD to the transistor drain)
  Transistor AP9465GEM: source to ground, drain = output Vo_cs
  Gate driven by VGG = 1.8 V DC in series with Vin1 = AC 1 V
  Analysis: .ac dec 10 1 100meg


--------------------------------------------------------------
PART 1 : GET THE SOFTWARE AND THE TRANSISTOR MODEL
--------------------------------------------------------------
1. LTspice (free)
   a. Open a browser, go to analog.com and search "LTspice".
   b. Click the Download button for Windows, run the installer,
      accept the defaults, finish.
   c. (Lab PC: LTspice is already installed, skip this.)

2. AP9465GEM model
   a. Search the web for "AP9465GEM SPICE model" (maker: APEC,
      a-poweric.com, product page, "SPICE model" download) or ask
      your lab teacher for the file your lab uses.
   b. Save it as   C:\ADCMOS\Exp1\AP9465GEM.lib
      (create the folders C:\ADCMOS and C:\ADCMOS\Exp1 first with
      File Explorer: right-click > New > Folder).
   c. Open that file in Notepad (right-click > Open with > Notepad).
      Look for the first line that starts with  .MODEL  or  .SUBCKT
      - write down the exact name after it (for example AP9465GEM)
      - write down whether it says NMOS or PMOS (or, if SUBCKT,
        which pin order it uses: usually D G S).
      Your journal circuit works as an N-channel amplifier (source to
      ground, gate biased positive, drain to +12 V through RD). Use the
      transistor symbol that matches what the file says.

   NO MODEL FILE? Use LTspice's built-in transistor instead:
   in Part 3 step 14 add the line
      .model NMOD NMOS(Kp=0.2 Vto=1.5 Lambda=0.02 Cgdo=1n Cgso=1n)
   and set the transistor Value to NMOD. Your gain/bandwidth numbers
   will differ from the journal, but all the steps are the same.


--------------------------------------------------------------
PART 2 : OPEN A NEW SCHEMATIC AND SAVE IT
--------------------------------------------------------------
3. Start LTspice.
4. Menu: File > New Schematic. A blank grid opens.
5. Menu: File > Save As, go to C:\ADCMOS\Exp1, name it
   cs_amp.asc, Save.
   (Save in the same folder as AP9465GEM.lib so LTspice can find it.)


--------------------------------------------------------------
PART 3 : PLACE THE COMPONENTS
--------------------------------------------------------------
Tools you will use (top toolbar of LTspice):
  Component icon (shape of an AND gate)   = key  F2
  Wire (pencil) icon                       = key  F3
  Label Net icon  (A with box)             = key  F4
  Ground icon                              = key  G
  Rotate                                   = Ctrl+R
  Mirror                                   = Ctrl+E
  Delete                                   = key  F5 (then click item)
  Move                                     = key  F7
  Stop any tool                            = Esc or right-click

6. TRANSISTOR (M1)
   a. Click the Component icon (or press F2). A "Select Component
      Symbol" window opens with a search box.
   b. Type  nmos  (or pmos if your model file said PMOS).
   c. Click the symbol in the list, click OK.
   d. Move the mouse to the middle of the grid, left-click once to
      drop it. Press Esc to stop placing.
   e. Right-click the transistor. If a list window "Pick New MOSFET"
      opens and your model name is in it, select it and OK. If not,
      click Cancel, then hold Ctrl and right-click the transistor
      (this opens the Component Attribute Editor). In the box named
      Value type the model name from step 2c (AP9465GEM). OK.

7. RESISTOR RD
   a. Click the Component icon (F2), type  res , select it, OK.
   b. Drop it above the transistor. Press Ctrl+R before clicking if
      you want it vertical. Esc to stop.
   c. Right-click the resistor, in the Resistance box type  100  ,
      OK.

8. VOLTAGE SOURCES (3 of them: VDD, VGG, Vin1)
   a. F2, type  voltage , select "voltage", OK. Drop one source at
      the top-left (this will be VDD). Drop two more at the left,
      stacked vertically (VGG on top, Vin1 below it). Esc.
   b. Right-click VDD source: in "DC value" type 12, OK.
   c. Right-click the VGG source: DC value 1.8, OK.
   d. Right-click the Vin1 source:
        - DC value: 0
        - Click the "Advanced" button.
        - In the "Small signal AC analysis(.AC)" section, in the
          box "AC Amplitude" type 1.
        - OK, OK.
   e. Rename them if you like: right-click the text "V1" next to
      the symbol and type VDD / VGG / Vin1.

9. GROUNDS
   Press G (or click the Ground icon, the downward triangle symbol).
   Click once below the transistor source, once below the Vin1
   source, once below the VDD source. Esc.


--------------------------------------------------------------
PART 4 : WIRE EVERYTHING
--------------------------------------------------------------
10. Press F3 (wire tool). Click on a component pin, click on the pin
    you want to join, the wire is drawn. Esc to stop.
    Make these connections:
      a. VDD + terminal  -> top of RD
      b. VDD - terminal  -> ground
      c. bottom of RD    -> transistor DRAIN pin
      d. transistor SOURCE pin -> ground
      e. transistor GATE pin -> + terminal of VGG
      f. VGG - terminal  -> + terminal of Vin1
      g. Vin1 - terminal -> ground
    Check: the gate is driven by Vin1 and VGG in series. This puts
    the 1.8 V DC bias and the AC signal together at the gate.

11. LABEL THE NODES (so the plot has readable names)
    a. Press F4. A "Net Name" box opens.
    b. Type  Vo_cs , OK. Click on the wire at the junction of RD and
       the drain. Click.
    c. Press F4 again, type  Vin_cs , OK, click on the wire at the
       transistor gate.
    d. Esc.


--------------------------------------------------------------
PART 5 : MODEL FILE AND ANALYSIS COMMAND
--------------------------------------------------------------
12. Add the model file line
    a. Press S (or click the ".op" icon on the toolbar = Spice
       Directive). A text box opens.
    b. Type exactly:   .lib AP9465GEM.lib
    c. OK. Click on an empty area of the schematic to place the text.
    (Skip this step if you used the built-in NMOD model, and do
    step 14 instead.)

13. Add the AC analysis command
    a. Menu: Simulate > Edit Simulation Cmd.
    b. Click the tab "AC Analysis".
    c. Type of Sweep: Decade.
       Number of points per decade: 10
       Start Frequency: 1
       Stop Frequency: 100meg
    d. OK. Click on an empty area to place the line. It reads:
       .ac dec 10 1 100meg
       (Type "meg" for mega. Plain "m" means milli in SPICE.)

14. (Only if no model file) press S and type the .model line from
    Part 1, OK, place it.


--------------------------------------------------------------
PART 6 : CHECK THE DC BIAS FIRST (2 minutes, saves trouble)
--------------------------------------------------------------
15. Press S, type   .op   , OK, and place it. TEMPORARILY delete or
    comment out the .ac line (right-click the .ac text, delete). Only
    one analysis can be active.
16. Click Run (running-man icon) or Simulate > Run.
17. A window with node voltages appears. Find V(vo_cs) = the drain
    DC voltage. It should be between about 1 V and 11 V. If it is
    exactly 12 V the transistor is OFF (check polarity of model,
    check the gate bias). If it is near 0 V the transistor is hard on.
18. Close the window, delete the .op line, put the .ac line back
    (Simulate > Edit Simulation Cmd > AC Analysis, same values).


--------------------------------------------------------------
PART 7 : RUN THE AC ANALYSIS AND READ THE RESULT
--------------------------------------------------------------
19. Click Run. A black plot window opens (empty at first).
20. Move the mouse over the net named Vo_cs on the schematic. The
    pointer becomes a red probe. Click once. The plot shows:
      solid line  = gain in dB (left axis)
      dashed line = phase in degrees (right axis)
21. READ THE MID-BAND GAIN
    a. Left-click the trace name V(vo_cs) printed at the top of the
       plot. A "Cursor 1" box appears with Freq, Mag, Phase.
    b. Drag the small cursor marker along the flat part of the curve
       (around 100 Hz to 10 kHz). Write down Mag (dB).
       Your journal curve is flat at roughly 38 to 39 dB.
    c. Convert: gain in V/V = 10 ^ (dB / 20).
       Example: 39 dB = about 89 times.
22. FIND THE UPPER CUTOFF FREQUENCY fH
    a. Keep dragging the cursor to the right until Mag equals
       (mid-band dB minus 3 dB). Example: 39 - 3 = 36 dB.
    b. Write down the Freq shown at that point. That is fH.
    c. Bandwidth = fH (there is no low-frequency roll-off because
       the input is DC-coupled).
23. CHECK THE PHASE
    The dashed line starts near 180 degrees at low frequency (the
    amplifier inverts) and falls as frequency rises.
24. SAVE A PICTURE FOR THE JOURNAL
    Press the Windows key + Shift + S (Snipping Tool), drag over the
    plot, paste into Paint or Word, save. Do the same for the
    schematic window.

OPTIONAL: TWO SEPARATE PANES LIKE YOUR JOURNAL
    Right-click in the plot area > Add Plot Pane. Click on the empty
    new pane to make it active, then click the Vo_cs net again. A
    combined magnitude+phase plot in one pane is also acceptable.


--------------------------------------------------------------
PART 8 : WRITE THIS IN YOUR JOURNAL
--------------------------------------------------------------
Observation table
  Mid-band gain (dB)            = ______
  Mid-band gain (V/V)           = ______
  -3 dB upper cutoff fH         = ______
  Phase at low frequency        = ______ (about 180 degrees)

Conclusion (use your own numbers)
  "The common source amplifier gave a mid-band gain of ___ dB with
  180 degree phase shift. The gain falls beyond ___ Hz because the
  gate-drain capacitance is multiplied by the Miller effect, which
  raises the input capacitance."


--------------------------------------------------------------
IF SOMETHING GOES WRONG
--------------------------------------------------------------
Plot is empty or flat at 0 dB:
   AC Amplitude on Vin1 is missing. Right-click Vin1 > Advanced >
   AC Amplitude = 1.
Error "Could not open library file" or "unknown subcircuit":
   The .lib file is not in the same folder as cs_amp.asc, or the
   file name in the .lib line is spelled differently.
Error "unknown model":
   The Value you typed on the transistor does not match the name
   after .MODEL in the file.
Gain is tiny, drain stays at 12 V:
   The transistor is off. Wrong polarity (NMOS vs PMOS) or VGG
   too low.
Used "m" for mega and the plot stops at 100 kHz:
   Type meg, not m.
