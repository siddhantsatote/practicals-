# Experiment 08: 2:1 Multiplexer (Logic Gates & Transmission Gates)

## Aim
To design, layout, and simulate a 2:1 Multiplexer in Microwind using:
1. Logic Gates (Inverter + NAND gates)
2. Transmission Gates (CMOS TG switch)
and compare transistor count, propagation delay, and layout area between the two approaches.

## Files in this Folder

### 1. Microwind Layout Files (.MSK)
| File | Implementation | Description | Nodes |
|------|----------------|-------------|-------|
| `Exp08_mux2to1.MSK` | Logic Gates & TG | Dual 2:1 MUX layouts (left: compiled gate design, right: optimized TG cell) | Inputs: `in0`, `in1`, `sel`; Output: `out_f` |
| **`Exp08_mux2to1_transmission_gate.MSK`** | **Pure Transmission Gate 2:1 MUX** | Standalone 2:1 MUX built with 2 TGs + 1 Inverter (6 transistors, Part B) | Inputs: `in0`, `in1`, `sel`; Output: `out_f` (visible) |
| `Exp08_transmission_gate.MSK` | Transmission Gate | Pure NMOS + PMOS parallel transmission gate | Clocks: `Enable`, `~Enable`; Data: `DataIn` to `DataOut` |
| `Exp08_transmission_gate_switch.MSK` | Transmission Gate Switch | TG with built-in CMOS inverter for complementary enable generation | Control: `Enable`; Data: `DataIn` to `DataOut` |

### 2. Verilog Synthesis Files (.v)
- **`mux_gates.v`**: Gate-level multiplexer description for automatic layout compilation:
  ```verilog
  module mux_gates(input X0, input X1, input S, output Y);
      wire Sb, a, b;
      assign Sb = ~S;
      assign a  = ~(X0 & Sb);
      assign b  = ~(X1 & S);
      assign Y  = ~(a & b);
  endmodule
  ```

---

## Truth Table & Function
Boolean equation: $Y = \overline{S} \cdot X_0 + S \cdot X_1$

| S (Select) | X0 | X1 | Y (Output) |
|:----------:|:--:|:--:|:----------:|
| 0 | 0 | X | **0** |
| 0 | 1 | X | **1** |
| 1 | X | 0 | **0** |
| 1 | X | 1 | **1** |

---

## Comparison Table
| Metric | Logic Gates (NAND/INV) | Transmission Gates |
|--------|------------------------|--------------------|
| **Transistor Count** | 14 transistors (1 INV + 3 NAND2) | 6 transistors (2 TGs + 1 INV) |
| **Logic Levels** | Fully regenerated by CMOS drivers | Full rail-to-rail passing (no threshold drop) |
| **Area** | Larger layout footprint | Very compact (~55% area reduction) |
| **Propagation Delay** | 2 gate delays | Minimal series channel resistance $R_{on}$ |

---

## How to Simulate in Microwind
1. Open `Exp08_mux2to1_transmission_gate.MSK` (for standalone TG version) or `Exp08_mux2to1.MSK`.
2. Check **Analysis > Design Rule Checker**.
3. Click **Simulate > Run Simulation**.
4. In **Voltage vs time**:
   - Verify that when $S = 0$, $Y$ follows $X_0$.
   - Verify that when $S = 1$, $Y$ follows $X_1$.
