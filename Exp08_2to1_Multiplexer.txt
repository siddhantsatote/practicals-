==============================================================
EXPERIMENT 8 : 2:1 MULTIPLEXER USING LOGIC GATES AND
               TRANSMISSION GATES
Complete start-to-finish guide  (tool: Microwind)
==============================================================

NOTE ON MENU NAMES
Microwind menus and icon names differ a little between versions
(your journal shows 3.9). If an item is not exactly where this guide
says, look in the neighbouring menu or hover over the palette icons.

AIM
To design a 2:1 multiplexer (a) with logic gates and (b) with
transmission gates, and verify the output by simulation.

FUNCTION
  Y = (not S).X0 + S.X1
     S X0 X1 | Y
     0  0  x | 0
     0  1  x | 1
     1  x  0 | 0
     1  x  1 | 1
  (x = don't care)


--------------------------------------------------------------
PART 1 : GET MICROWIND AND SET UP
--------------------------------------------------------------
1. Lab PC: start MICROWIND. Own laptop: microwind.net > Downloads >
   MICROWIND student version > install defaults > start it.
2. Make folder C:\ADCMOS\Exp8
3. File > Select Foundry > choose the lab's rule file (ask your lab
   teacher; your journal layout used L = 0.03 um) > Open.
   Then File > New.


==============================================================
(A) MUX USING LOGIC GATES
==============================================================
4. Notepad (Start menu > Notepad). Type:
        module mux_gates(input X0, input X1, input S, output Y);
          wire Sb, a, b;
          assign Sb = ~S;
          assign a  = ~(X0 & Sb);
          assign b  = ~(X1 & S);
          assign Y  = ~(a & b);
        endmodule
5. File > Save As > C:\ADCMOS\Exp8 > file name mux_gates.v >
   Save as type: All Files > Save.
6. Microwind: File > New. Compile > Compile Verilog File >
   mux_gates.v > Open. The layout appears. File > Save As
   mux_gates.MSK. (View > Zoom All to see all of it.)
7. Clocks: Click the Clock icon in the right palette, click the pin
   S, set period 800 ps, OK. Do the same: X0 period 200 ps, X1 period
   400 ps. (This makes S switch slowest so you see X0 and X1
   selected in turn.)
8. Visible node icon: click on the Y output.
9. Analysis > Design Rule Checker > run.
10. Simulate > Run Simulation > tab Voltage vs time > Run. Time scale
    long enough for at least 1 ns; click More to extend.
11. Check: while S is low, Y follows X0. While S is high, Y follows
    X1. Screenshot. Note delay: tick Delay, choose between S and Y,
    click an S edge and the following Y edge.

HAND-DRAWN VERSION (if your teacher wants the transistor layout)
12. Build one inverter for Sb: MOS generator > n-MOS W 0.08 L 0.03 +
    p-MOS W 0.108 L 0.03, p-MOS above n-MOS, poly joined for input,
    drains joined for output, sources to the rails.
13. Build three 2-input NAND gates. For each one:
    - n-MOS: MOS generator > n-MOS, W 0.16 um, L 0.03 um, Number of
      gates 2 (this makes the two series transistors on one strip:
      left contact = output, right contact = VSS, middle = internal
      node with no contact).
    - p-MOS: MOS generator > p-MOS, W 0.108 um, L 0.03 um, Number of
      gates 2, placed above (these are the two parallel transistors:
      outer contacts to VDD, middle contact = output).
    - Join the two poly lines of the NMOS to the two poly lines of
      the PMOS (first with first, second with second) and join the
      PMOS middle contact to the NMOS left contact with Metal 1.
14. Wire: NAND1 inputs X0 and Sb; NAND2 inputs X1 and S; NAND3
    inputs = outputs of NAND1 and NAND2; NAND3 output = Y. Use Metal
    1 for wires and contacts where layers meet.
15. Add Vdd, Vss, clocks on S, X0, X1, Visible node on Y, DRC,
    simulate as in steps 7 to 11.


==============================================================
(B) MUX USING TRANSMISSION GATES (6 transistors)
==============================================================
Concept: each transmission gate (TG) is one NMOS and one PMOS in
parallel. When the NMOS gate is high and the PMOS gate is low, the TG
passes the signal. Two TGs share the output Y; the select signal S
and its complement Sb turn exactly one of them on.

16. File > New. File > Save As mux_tg.MSK.
17. INVERTER for Sb
    MOS generator > n-MOS, Width 0.08 um, Length 0.03 um, 1 gate >
    Generate device > drop low-left. MOS generator > p-MOS, Width
    0.108 um, Length 0.03 um, 1 gate > Generate > drop above it.
    Join the two poly gates (draw a red poly strip between them),
    put a contact on that poly for input S. Join the two drains with
    a blue Metal 1 strip: that is Sb. Sources: PMOS left contact to
    the VDD rail above, NMOS left contact to the VSS rail below.
18. TRANSMISSION GATE 1 (passes X0)
    MOS generator > n-MOS, W 0.1 um, L 0.03 um > Generate > drop
    beside the inverter in the lower row. MOS generator > p-MOS, W
    0.1 um, L 0.03 um > Generate > drop directly above it.
      - Join the two LEFT contacts (sources) with Metal 1: this is
        input X0.
      - Join the two RIGHT contacts (drains) with Metal 1: this is
        output Y.
      - NMOS gate (poly) connects to Sb. PMOS gate connects to S.
19. TRANSMISSION GATE 2 (passes X1)
    Generate a second NMOS and PMOS pair, same sizes, placed to the
    right.
      - Join the two LEFT contacts: input X1.
      - Join the two RIGHT contacts: connect to the same output Y as
        TG1 (a Metal 1 strip joining both drains).
      - NMOS gate = S. PMOS gate = Sb.
20. WIRING NOTES
    Gate wires: red poly strips. Source/drain wires: blue Metal 1.
    Put a contact (palette icons: contact poly/metal or
    contact diffusion/metal) wherever a poly or diffusion must meet
    Metal 1.
    The p-MOS devices sit in the n-well; Microwind draws it
    automatically. Connect the NMOS bulk to VSS and PMOS bulk to VDD:
    the MOS generator adds bulk contacts; if not, add a diffusion
    contact to the rail near each transistor.
21. PROPERTIES
    Vdd icon on the VDD rail; Vss icon on the VSS rail; Clock icon on
    S (800 ps), X0 (200 ps), X1 (400 ps); Visible node on Y.
22. Analysis > Design Rule Checker; fix errors.
23. Simulate > Run Simulation > Voltage vs time > Run. Y should follow
    X0 when S = 0 and X1 when S = 1, with full logic levels. Screenshot.
24. Note delay and power as in step 11. Compare with (A).

--------------------------------------------------------------
IF SOMETHING GOES WRONG
--------------------------------------------------------------
Y floats or is unknown at some times: one TG has its S/Sb gate
   connections swapped. The NMOS gate must be HIGH when that path is
   selected.
Y is weak or wrong when S switches: both TGs on at the same time
   because Sb is not the complement of S. Check the inverter.
Verilog compile error: the file was saved as .txt, or a missing
   semicolon.
